## 3. 実装済み機能リスト (Implemented Features - v2.0 Standard)

Google AntiGravity + MCPにより、以下の機能が**実装・動作確認済み (Proven)** です。これらは「空想」ではなく、実機で動く機能です。

### A. Core Architecture (脳)

* **MCP Orchestrator:** Google AntiGravityが「指揮者」となり、複数のアプリ（Blender/Unity）を同時制御。
* **Seamless Bridge:** UnityとBlender間でのデータ消失（マテリアル、UV）を防ぐ独自パイプライン。

### B. Blender MCP (造形)

* **Text-to-Mesh:** 自然言語指示による3Dモデリング（「氷の剣」「ピタゴラ装置」などで実証済み）。
* **Smart UV:** `smart_uv_project` によるUV自動展開（テクスチャ崩れやエラーを防止）。
* **Material Gen:** 透明度、発光（Emission）を含むPBRマテリアル設定の自動化。
* **Auto-Export:** Unity座標系（-Z Forward, Y Up）への自動変換付きFBX出力。

### C. Unity MCP (構築)

* **Hot Import:** FBX出力を検知し、即座にインポート処理を開始（待機時間ゼロ）。
* **Auto-Prefab:** インポートしたモデルを自動でPrefab化し、シーンに配置。
* **Physics Setup:** Rigidbody, Collider等の物理コンポーネントを自動付与。
* **Scene Control:** 座標、回転、親子関係（Hierarchy）の操作。

### D. Infrastructure (基盤)

* **Git Time Machine:** アセット生成ごとに自動コミット（`git_commit`）し、履歴を保護。
* **Self-Check:** `git_status`, `git_diff` による自己診断機能。
* **Founder License System:** 手数料優遇（0% or 10%）を適用するライセンスキー認証（仕様策定済み）。

## 4. 戦略的決定事項 (Strategic Decisions)

プロジェクト進行中に確定した、重要なマーケティング戦略のまとめです。

### A. 「共犯者」戦略 (The Accomplice Strategy)

* **決定:** ユーザーを単なる「客」ではなく、共に業界を変える「共犯者 (Insider)」として扱う。
* **理由:** 知名度のない個人開発者が大手に勝つには、熱狂的なファンコミュニティが必要だから。
* **実装:** リターンに「Founder's License（将来の特権）」を含め、Discordでの密な交流（Air Co-Dev）を売りにする。

### B. 「魔法と論理」の二段構え (Magic & Logic)

* **決定:** 冒頭では「魔法のように簡単」と見せ、後半で「MCPによる技術的裏付け」を語る。
* **理由:** 初心者は簡単さに惹かれるが、玄人（高額支援者）は技術的な納得感を求めるため。
* **実装:** ページの構成順序を「Hook (痛み) -> Magic (解決) -> Logic (技術)」とした。

### C. アンチ・スケプティック対策 (Anti-Skeptic Defense)

* **決定:** 「AIラッパーだろ」「サブスクにするんだろ」「Mac非対応かよ」という批判に先回りして回答する。
* **理由:** ネット上の批判は伝染しやすいため、最初から「誠実さ（Radical Honesty）」で武装する。
* **実装:** FAQセクションでこれらに正直に答え、逆に「だからこそ今支援が必要だ」という論理に変換した。
