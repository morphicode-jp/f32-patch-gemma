## 2. カテゴリ・チャンネル構成

### 📂 00-ENTRANCE (Read Only)

* **`#📜-rules` (ルール)**: サーバー利用規約。
* **`#👋-welcome` (玄関)**: 入室通知場所。
* **`#🎫-verification` (認証所)**: Ticket Tool設置場所。

### 📂 01-PUBLIC LOUNGE (Open to All)

* **`#💬-general` (雑談・質問)**: 誰でも書き込める雑談所。
* **`#📣-announcements` (公式アナウンス)**: 進捗やデモ通知。

### 📂 02-AETHER LAB (🔒 Standard以上)

* **`#🗳️-feature-voting` (機能投票)**: 機能開発のアンケート場所（書込禁止）。
* **`#📺-dev-live` (開発実況)**: 無編集動画や進捗スクショ（書込禁止/リアクションのみ）。
* **`#💡-ideas` (妄想置き場)**: ユーザーのアイデア投稿所。

### 📂 03-INSIDER BUILD (🔒 Pro Insider以上)

* **`#📦-beta-download` (ダウンロード)**: Beta版配布（流出厳禁）。
* **`#🐛-bug-report` (バグ報告)**: 不具合報告。

### 📂 04-GOD SANCTUARY (🔒 God Modeのみ)

* **`#🍷-vip-lounge`**: VIP専用ライン。

## 4. コピペ用テキスト素材 (Copy & Paste Assets)

以下のテキストを各チャンネルにそのまま貼り付けてください。

### 📜 #rules (ルール)

```markdown
**👋 AETHER 開発室へようこそ！**

ここは「思考を現実に変える」ための共創コミュニティです。
快適なラボであるために、以下の3つのルールを守ってください。

**1. Respect Creator & Code**
開発者もAIも、そしてあなたも、ここでは対等な「クリエイター」です。
暴言、ハラスメント、過度なマウント行為は即BAN対象となります。敬意を持って接しましょう。

**2. No Leaks (秘密厳守)**
「Pro Insider」以上のチャンネルで共有される**Beta版のダウンロードリンク**や、未公開の開発情報は**外部持ち出し厳禁**です。
もし流出が見つかった場合、法的措置およびライセンスの永久停止を行います。

**3. Enjoy the Chaos (混沌を楽しもう)**
AETHERは開発途中のエンジンです。バグります。クラッシュします。
それを「祭り」として楽しめる心の余裕を持って参加してください。
バグ報告は `#🐛-bug-report` まで！

---
**✅ 同意する**
このサーバーに参加した時点で、上記ルールに同意したものとみなします。
```

### 🎫 #verification (認証所)

```markdown
**🎉 支援者限定ロールの申請所**

AETHERをご支援いただき、ありがとうございます！
ここではクラウドファンディング支援者（Standard / Pro / God）へのロール付与を行います。

**▼ 手順 (How to Verify)**

1. 下の **「📩 Create ticket」** ボタン（または鍵マーク）を押してください。
2. あなただけの「個室チャット」が作成されます。
3. そのチャットに、**「支援完了画面」または「決済メール」のスクリーンショット**を貼り付けてください。
   *(※注文IDやお名前が見えるようにしてください)*
4. 開発者が確認次第、手動でロール（役職）を付与します。

**⚠️ 注意事項**
* ロール付与まで数時間〜24時間程度かかる場合があります。気長にお待ちください。
* 個人情報はロール付与以外の目的には使用しません。
```
