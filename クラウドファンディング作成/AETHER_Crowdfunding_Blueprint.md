# 📘 AETHER プロジェクト・マスターバイブル (Final Version)

## 1. ブランド・アイデンティティ

* **プロジェクト名:** **AETHER** (エーテル)
  * **表記:** 必ず「AETHER」またはロゴとして「ÆTHER/Æ」を使用。
* **キャッチコピー:**
  * **「『思考』と『創造』の境界を溶かす。言葉ひとつで、世界は動く。」**
  * **「UnityとBlenderを『直結』する、AIパイプライン・エンジン。」**
* **コンセプト:**
  * 従来の「ファイル転送」という概念を捨て、AIがアプリケーション間のメモリを直接操作する次世代のワークフロー。
  * ※注記: 「第五元素」という表現は使用禁止。

## 2. ストーリーテリング（Kickstarterメソッド）

読者を「共感」から「信頼」へ導く構成。

* **The Hook (痛み):**
  * クリエイター＝「デバッグ係」という悲しい現状。
  * BlenderからUnityへのインポート時の「軸ズレ（顔面埋まり）」や「ピンク色の世界」の絶望。

* **The Origin (物語):**
  * **「2年間の敗北と、48時間の熱狂」**。
  * 2年間、AI活用に失敗し続け、プロジェクトの墓場を築いた開発者が、AntiGravity/MCPと出会い、寝食を忘れて没頭した週末の記録。
  * 「私が踏み抜いた地雷原は、安全な道に変えておいた」というメッセージ。

* **The Proof (証拠):**
  * **「無編集・ノーカット」の実演デモ動画**（タスクマネージャーや時計を表示）を提示し、詐欺ではないことを証明する。

## 3. 技術的裏付け (How it Works)

ページ後半に配置し、エンジニア層の信頼を獲得する。

* **アーキテクチャ:** Google AntiGravity × **MCP (Model Context Protocol)** 。
* **仕組み:**
  * 従来のファイルベース連携ではなく、`mcp-unity` と `mcp-blender` エージェントがリアルタイムに通信し、モデリングと同時にコンポーネント設定を行う「完全統合」システムであることを図解する。
