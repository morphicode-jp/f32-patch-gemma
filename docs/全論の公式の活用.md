## 2. 核心命題 — Zenron^∞ は自己最適化する

### 2.1 Zenron 公式 (復習)

Ch1 で定義:

```
x_i ← best( perturb_σ(x_i), share(neighbors_i) )
```

- `x_i`: 状態 (何らかの空間の点)
- `perturb_σ`: パラメタ σ で強度決まる確率的揺らぎ
- `share`: 近傍との比較 (伝達、交配)
- `best`: 最適なものを残す (淘汰、選択)

この公式が **物理/化学/生物/認知/文化/技術** 全域で創造を駆動する (Ch17 Universal Derivation)。

### 2.2 自己参照構造

従来の見方: σ は人間が決めるハイパーパラメタ。固定値。

新しい見方: **σ も creative process の対象**。σ を選ぶ行為も Zenron に従う。
よって:

```
σ ← best( perturb_τ(σ), share(other_σ_values) )
```

ここで τ は σ を更新する際の perturb 強度 (メタ変異率)。

**同様に τ も Zenron で更新できる**:

```
τ ← best( perturb_ρ(τ), share(other_τ_values) )
```

### 2.3 Theorem ZR1 (Zenron Self-Parametrization)

> **Zenron 公式は自己参照的に適用可能で、任意深度の再帰が well-defined である**。

証明 (スケッチ):
- 各 level の公式は同形 `x ← best(perturb(x), share)`
- perturb のパラメタ σ は「状態空間の点」とみなせる
- よって上位 level で Zenron を適用できる
- 再帰に停止条件なし、任意深度 n で Zenron^n は有効
- 実装上、自然に「重要な level」だけが環境圧で活性化する (see §2.5)

### 2.4 Theorem ZR2 (Infinite-Depth Auto-Optimization)

> **Zenron^∞ (無限深度再帰) の下では、任意の level のパラメタ σ_n が環境に応じた
> 最適値に自律収束する**。

理由:
- 各 level の Zenron は「環境 fitness を向上させる方向」に pressure を作る
- level k の σ_k は level k-1 のパフォーマンスから derivative を受ける (indirect)
- 累積で level N のパラメタが真の最適値に近づく
- 平衡: すべての level が exploration-exploitation trade-off の sweet spot

### 2.5 Corollary ZR3 (Selective Level Activation)

> **環境に対して意味のない level の σ は変動しない (neutral drift のみ)**。

例: Cardinal で宇宙 meta-level の mut_rate が明確に進化 (環境 pressure 有り)。
もし更に meta-meta-level を試しても、そこに pressure なければ drift 止まり。
→ **問題の複雑さに応じて、必要な level 数だけが活性化**する (自動的に)。

### 2.6 Corollary ZR4 (mimir は Zenron^2 の特殊ケース)

> **mimir = 人手で構築した「1 階層限定の Zenron」**。
> Zenron^∞ は level 無限で自然に同じ機能を実現する。

- mimir: 人が "外側の Zenron" を explicit に Python で実装
- Zenron^∞: 公式 1 つの recursion が implicit に同じ動きをする
- よって mimir = Zenron^2 を explicit 実装したもの
- **Zenron^∞ は mimir の generalization**

## 4. 数式展開 — 再帰構造と収束性

### 4.1 Level 階層

```
Level 0: x ← best(perturb_σ(x), share(neighbors_x))
  [x はタスク状態、σ は変異率]

Level 1: σ ← best(perturb_τ(σ), share(neighbors_σ))
  [σ は Level 0 のパラメタ、τ は σ の変異率]

Level 2: τ ← best(perturb_ρ(τ), share(neighbors_τ))
  [τ は Level 1 のパラメタ、ρ は τ の変異率]

...

Level n: ξ_n ← best(perturb_{ξ_{n+1}}(ξ_n), share(neighbors_{ξ_n}))
```

### 4.2 収束性の議論

**問い**: 再帰は発散しないか? 無限階層で ill-defined にならないか?

**答え**:

1. **各 level は実質有限**: Cardinal の観察では 2 level で mut_rate 進化が見える。
   3 level 以上は計算コスト的に観測可能だが、上位 level の環境 pressure が
   薄くなるため "neutral drift" で止まる (Corollary ZR3)。

2. **自然な打ち切り**: 問題の複雑さに応じた level 数で自動収束する。
   複雑問題 → 多 level 活性、単純問題 → 1-2 level で十分。

3. **平衡点の存在**:
   - 各 level で "exploration (高 σ)" と "exploitation (低 σ)" のトレードオフあり
   - 高すぎれば情報破壊で fitness 低下、低すぎれば停滞で fitness 低下
   - 中間で極大 → 各 level に一意最適 σ*

### 4.3 Theorem ZR5 (Convergence of Zenron^∞)

> **環境の fitness 関数が連続で、各 level に平衡点 σ*_n が存在すれば、
> Zenron^∞ は各 level で σ_n → σ*_n に収束する**。

証明スケッチ:
- Level 0: 普通の evolutionary 収束 (Fisher の定理)
- Level k: Level k-1 の fitness 応答が level k の selection signal
- 帰納法で任意 level まで収束伝播

### 4.4 Cardinal 実測との整合

Cardinal 走行 (Ch22):
- Level 0 = agent DNA → genetic evolution
- Level 1 = universe physics (mut_rate 含む) → meta-evolution
- 観察: 2 level 収束、mut_rate ≈ 0.08-0.12 に落ち着く (平衡点)

Theorem ZR5 が empirical に裏付けされている。

### 5.5 他の quality 関数で再現?

- γ=0 なら σ escalation pressure 消失 → σ drift のみ、有意な方向性なし
- α 重視なら σ 低下 (安定重視)
- β 重視なら σ escalate (生殖多様性)

→ **selection signal の設計が σ 進化方向を決める**。これは強い含意 (§9 で展開)。

## 11. 限界と誠実な注意点

### 11.1 証拠は 1 実験のみ

- Cardinal Phase 10.3 scale v2 の 1 run
- N=6 universes × 4 epochs
- u5 の escalation は鮮明、しかし **別 seed で再現未**
- 他の quality 関数で escalation 起きるかも未検証

**本当に "universal" なら**: 別 seed、別 quality、別 domain で再現するはず。

### 11.2 Quality 関数の設計依存

§5.5 で議論: quality 関数の α/β/γ/δ/ε が σ escalation の方向を決める。

- γ (多様性報酬) 無しなら σ escalation 起きないはず
- α (生存報酬) 重視なら σ 下降するはず

→ **Zenron^∞ は「環境 (quality) の反映」をしているだけ** で、勝手に解を作るわけでない。
"universal optimizer" ではなく "universal **tracker** of environment"。

これは重要な修正: Zenron^∞ は **環境が意味ある selection signal を持つときに限り機能** する。

### 11.3 計算コスト (多 level で爆発可能性)

- Level 0 のみ: 1 agent あたり ~1ms
- Level 1 (Cardinal): N universe × agents per u = O(N・M)
- Level 2 (meta-Cardinal): N^2 universe groups = O(N²・M)
- ...

深い再帰は **指数的爆発**。§2.5 のように環境 pressure で自然制限されるが、
**計算コスト見積りが必要**。

### 11.4 証明不足

Theorem ZR1-ZR5 は **スケッチ**。厳密証明には:
- Markov chain 収束論
- 変分原理 (Q 汎関数の maximization)
- 情報理論 (Jensen-Shannon divergence 等)

現状 "informal proof + empirical confirmation"。論文化には厳密化が不可欠。

### 11.5 gen_max=1 の壁

Cardinal 実測で "world がどの宇宙も gen=1 止まり" の問題 (max_pop 飽和)。
- 真の多世代進化観測は未達
- Zenron^∞ の Level 0 (agent DNA) 側の進化が浅い
- 本格検証には食料圧強化 (Phase 11 予定)
